# Third-party content

The MIT license in `LICENSE` covers the code of this project and the built-in
**Demo Cursor** set in `assets/bundled/Demo Cursor`, which was drawn from scratch by
`tools/make_demo_cursor.py`.

## Artists' cursor packs are not included

This repository ships **no third-party cursor packs**. Animated cursor packs are the work
of their artists, and many of them (including the ones this app was developed with) state
that publication or duplication is prohibited. Download packs from the creators yourself,
keep them in your own cursors folder, and do not commit them to a fork. For the same
reason the README screenshot shows only the demo set.

The links in the app point to the artists' own shops; nothing of theirs is copied.

`assets/bundled/` is an optional local folder for packs you have the rights to ship with
your own copy; apart from the demo set its contents are ignored by git.
