# assets/bundled

Cursor packs in this folder are treated as "built-in": they are always listed, whatever
cursors folder is selected in the app.

The repository ships exactly one: **Demo Cursor**, a simple placeholder set drawn from
scratch by `tools/make_demo_cursor.py` (MIT licensed like the rest of the code), so the app
has something to show before you add real packs. Packs from artists are never included,
because they belong to their creators and most forbid redistribution. Anything else you
put in this folder is ignored by git.
